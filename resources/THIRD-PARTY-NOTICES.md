# Third-party runtime components

This distribution includes the following upstream components. See the bundled licenses directory and Python package metadata for complete licenses and source information.

- CPython / Python Standalone Builds: PSF and bundled dependencies. https://github.com/astral-sh/python-build-standalone/releases/tag/20261021
- FFmpeg LGPL shared build: LGPL and bundled dependencies. Source and build configuration: https://github.com/BtbN/FFmpeg-Builds/releases/tag/autobuild-2026-09-30-13-08
- Deno: MIT and bundled dependencies. https://github.com/denoland/deno/releases/tag/v2.9.8
- yt-dlp: Unlicense, with dependency licenses in python/Lib/site-packages. https://github.com/yt-dlp/yt-dlp

Exact package versions and hashes are recorded in runtime-lock.json and runtime/inventory.json. No Authenticode signature is claimed.
